Privacy

Last updated September 5, 2026

Curve data stays in your browser

Motion Feel Lab has no account. In normal use, the latest curve stays in this browser’s local storage.

The sample demo uses a separate browser-storage key. Demo changes do not change normal curve data.

What leaves the browser

The editor does not send curve values, exports, or settings to us. Share links put curve values in the URL fragment, which browsers do not send in HTTP requests.

The app has no advertising, analytics, or third-party runtime scripts. Hosting can process standard request logs for security and reliability.

Your choices

Use Reset curve to replace normal curve data. Use Reset demo or Start for real to discard demo data. Clear this site’s browser storage to remove saved curve data.
